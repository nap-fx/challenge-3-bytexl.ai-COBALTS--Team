## 🎯 How to Use Skills in Antigravity (AGY) / Agent Workflows
Every skill in this vault contains a standardized `SKILL.md` file. 

To bring a skill into your active workspace or project:
1. **Option A (Workspace Copy):** Copy the desired skill folder directly into your project's `.agents/skills/` or `.claude/skills/` directory.
2. **Option B (Direct Reference):** Point your agent to read `C:\Users\Hp\Downloads\cobalts skill vault\<category>\<skill>\SKILL.md` at any time.
3. **Option C (AGY Customization):** You can also install any skill globally into your AGY config at `C:\Users\Hp\.gemini\antigravity\builtin\skills\` or through AGY plugins.
